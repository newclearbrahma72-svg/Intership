1. Data Collection / Loading
These functions let you read datasets from different sources.

    Pandas:
Code:
     import pandas as pd

     # CSV
     df = pd.read_csv("data.csv")

    # Excel
    df = pd.read_excel("data.xlsx", sheet_name="Sheet1")

    # JSON
    df = pd.read_json("data.json")

    # SQL
    import sqlite3
    conn = sqlite3.connect("mydb.sqlite")
    df = pd.read_sql("SELECT * FROM table_name", conn)

    # API / Web
    df = pd.read_html("https://example.com/table")[0]  # first table on page

Learn:

  pd.read_csv()
  pd.read_excel()
  pd.read_json()
  pd.read_sql()
  pd.read_html()


2. Data Inspection
Check dataset structure and quality.

Code:
    df.head()       # first 5 rows
    df.tail()       # last 5 rows
    df.info()       # column types & null counts
    df.describe()   # summary statistics
    df.shape        # (rows, columns)
    df.columns      # column names

Learn:
  head(), tail()
  info()
  describe()
  shape, columns


3. Data Cleaning
Handle missing values, duplicates, and formatting.

Code:
  df.dropna()                     # remove rows with NaN
  df.fillna(0)                    # replace NaN with 0
  df.drop_duplicates()            # remove duplicate rows
  df.rename(columns={'old':'new'})# rename columns
  df.astype({'Age': 'int'})       # change data type

Learn:
  dropna()
  fillna()
  drop_duplicates()
  rename()
  astype()

4. Data Selection & Filtering
Extract specific rows/columns.

Code:
  df['Name']                      # select column
  df[['Name', 'Age']]             # select multiple columns
  df[df['Age'] > 30]              # filter rows
  df.loc[0]                       # select by label
  df.iloc[0]                      # select by index position

Learn:
  [] column selection
  loc[]
  iloc[]
  Boolean filtering


5. Data Transformation
Modify or create new columns.

Python

Code:
  df['Score'] = df['Score'] * 1.1
  df['Category'] = df['Age'].apply(lambda x: 'Adult' if x >= 18 else 'Child')

Learn:
  apply()
  Vectorized operations (df['col'] * 2)
  map()


6. Grouping & Aggregation
Summarize data.

Code:
  df.groupby('Category')['Score'].mean()
  df.groupby(['Category', 'Passed']).agg({'Score': 'max', 'Age': 'min'})

Learn:
  groupby()
  agg()
  mean(), sum(), max(), min()

7. NumPy for Dataset Operations
NumPy is useful for fast calculations inside Pandas.

Code:
  import numpy as np

  np.mean(df['Score'])
  np.std(df['Score'])
  np.unique(df['Category'])

Learn:
  np.mean(), np.std()
  np.unique()
  np.array()
  np.arange(), np.linspace()


Skill Path for Data Collection & Preparation

  1> Loading: read_csv, read_excel, read_json, read_sql, read_html
  2> Inspecting: head, info, describe
  3> Cleaning: dropna, fillna, drop_duplicates, rename
  4> Selecting: loc, iloc, boolean filtering
  5> Transforming: apply, map, vectorized math
  6> Aggregating: groupby, agg
  7> NumPy basics: mean, std, unique, array creation
